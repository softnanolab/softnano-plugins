# Handoff document template

Copy this into `HANDOFF.md` at the repo root and fill every section. Replace `<...>` placeholders and delete the parenthetical guidance as you go. Keep the section numbering — the resume side reads it positionally.

Anything you did not verify with a command gets the literal marker `UNVERIFIED` next to it.
